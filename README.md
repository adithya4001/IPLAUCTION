> **Where Strategy Meets the Gavel: The Ultimate Indian Premier League Mega Auction Simulator**

An interactive, real-time multiplayer web application engineered to replicate the high-stakes environment of the IPL auction table. Designed for cricket enthusiasts, franchise strategists, and sports data analysts, this platform transforms the complex dynamics of bidding wars, purse management, and squad building into a seamless digital experience.

🔗 **[Launch Live Demo](https://iplauction-nine.vercel.app/)** 

---

## 🔥 Core Features

The simulator goes beyond basic bidding by incorporating comprehensive franchise management tools.

| Feature Category | Description |
| :--- | :--- |
| 💰 **Purse Calculations** | Dynamic real-time tracking of franchise budgets, remaining funds, and maximum bid limits based on current squad size. |
| 📊 **Historical Player Pools** | Access to a massive, meticulously categorized database of players spanning from the **2008 inaugural season to 2026**. |
| ⚙️ **Custom Auction Modes** | Flexible configurations to simulate different environments (e.g., full Mega Auction vs. localized Mini-Auctions). |
| 🌐 **Multiplayer Engine** | Real-time synchronization allowing multiple users to act as rival franchise owners simultaneously. |

### Player Filtering Mechanics
*   **Role-Based:** Batsmen, Bowlers, All-Rounders, Wicket-Keepers.
*   **Origin:** Domestic (Indian) vs. Overseas player cap tracking.
*   **Base Price:** Filter remaining pools by base price brackets.

## 🛠️ Technical Architecture

This application was architected with a focus on speed, real-time data handling, and clean code principles.

*   **Frontend Framework:** React.js powered by Vite for blazing-fast HMR and optimized production builds.
*   **Styling:** Tailwind CSS for a highly customized, mobile-responsive, and sleek dark-mode aesthetic.
*   **Development Methodology:** Prompt-Driven Development for rapid prototyping, component generation, and state management modeling.
*   **Hosting & CI/CD:** Vercel for zero-downtime automated deployments directly from the main GitHub branch.

## 🚀 Installation & Setup

To run the simulation locally, explore the code, or contribute to the project, follow these steps:

1. **Clone the Repository**
```bash
git clone [https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git](https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git)
```

2. **Navigate to the Workspace**
```bash
cd YOUR_REPO_NAME
```

3. **Install Dependencies**
```bash
npm install
```

4. **Initialize Local Server**
```bash
npm run dev
```
*The application will boot up on `http://localhost:5173`.*
